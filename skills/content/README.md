# Content

Making content as a tech/AI creator, starting from zero: choosing a specific angle and audience, finding video ideas with evidence, writing scripts for YouTube, Shorts, TikTok and Instagram Reels, and learning from the numbers after posting.

## Skills

| Skill | Status | What it does |
|---|---|---|
| [content-strategy](content-strategy/SKILL.md) | ✅ | Angle, viewer, three pillars, platforms and cadence, voice, first 30-day plan; saves the creator profile. Includes a beginner's platform primer |
| [content-ideas](content-ideas/SKILL.md) | ✅ | Ideas from your own work, audience questions, niche outliers and verified AI news; gated, scored and saved to a backlog |
| [video-script](video-script/SKILL.md) | ✅ | Hooks, a say/show script table, title and thumbnail, captions and on-screen text; also cuts Shorts from a long video and reviews scripts |
| [content-retro](content-retro/SKILL.md) | ✅ | Reads real analytics against your own median, finds the one biggest leak, sets one test, logs the lesson |

## How they connect

`content-strategy` (once, then every few months) → `content-ideas` → `video-script` → film and post (you, never the agent) → `content-retro` → back to `content-ideas`.

All four read the creator profile in `my-context` (`references/creator.md`) and share a `content/` folder in your working directory:

```
content/
  plan.md       first 30-day plan (content-strategy)
  ideas.md      scored idea backlog (content-ideas; status idea → scripted → posted)
  scripts/      one file per video (video-script)
  log.md        published videos, numbers, tests and lessons (content-retro)
```

None of these skills publish anything. They write drafts; you post.
