# Core

Always-on skills for any project: personal context, how to plan and clarify work, debugging, verification and handing work over between sessions.

Keep this pack small. Every installed skill's description is loaded into every session.

## Skills

| Skill | Status | What it does |
|---|---|---|
| [my-context](my-context/SKILL.md) | ✅ | Who you are, your goals, stack and projects, for other skills to read |
